DDL  - Data Definition Language
 DDL is used to create/change the structure of the database Object 

Main Commands
 CREATE 
 Alter 
 Drop 
 Truncate

To create Database:
    create database databasename
    create table table_name ( column_name datatype);

Alter : 
    Add 
    modify
    rename
    drop


ADD: 

Alter table Table_name  ADD column_name datatype;
eg: alter table students add city varchar(5);

Modify:
alter table tablename modify column_name datatype;

Rename: 

alter table tablename RENAME COLUMN col_name to new_column_name 

DROP : 
alter table tablename DROP COLUMN col_name;
